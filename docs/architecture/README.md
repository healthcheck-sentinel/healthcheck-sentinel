# Architecture

This folder will contain architecture diagrams for healthcheck-sentinel.

## Planned diagrams

- [ ] **System Context (C4 L1)** — how users, services, and external systems relate
- [ ] **Container Diagram (C4 L2)** — breakdown of FastAPI services, agent, and data stores
- [ ] **Sequence Diagrams** — health check polling, alert dispatch, ChatOps flow

Diagrams will be created with [Mermaid](https://mermaid.js.org/) (embedded in Markdown) and/or [draw.io](https://app.diagrams.net/).
